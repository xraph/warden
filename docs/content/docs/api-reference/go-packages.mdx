## Core Types

### warden.CheckRequest

```go
type CheckRequest struct {
    Subject       Subject        // Who is requesting
    Action        Action         // What action: Action{Name: "read"}
    Resource      Resource       // What: Resource{Type: "document", ID: "doc-1"}
    Context       map[string]any // Attributes for ABAC (context.<k> in conditions)
    TenantID      string         // Optional: overrides the context-derived tenant
    NamespacePath string         // Optional: overrides the context-derived namespace
}
```

### warden.CheckResult

```go
type CheckResult struct {
    Allowed     bool
    Decision    Decision    // "allow", "deny_explicit", "deny_no_roles", "deny_no_perms", ...
    Reason      string
    MatchedBy   []MatchInfo // what matched, with its source ("rbac", "rebac", "abac")
    Obligations []string    // from every matched policy
    EvalTimeNs  int64
}
```

### warden.Subject

```go
type Subject struct {
    Kind       SubjectKind // SubjectUser, SubjectAPIKey, ...
    ID         string
    Attributes map[string]any // subject.attributes.<k> in conditions
}
```

### warden.Config

```go
type Config struct {
    MaxGraphDepth       int           // default: 10
    CacheTTL            time.Duration // default: 0 (disabled)
    CacheMaxSize        int
    EnableRBAC          *bool // nil means the default, true
    EnableABAC          *bool // nil means true
    EnableReBAC         *bool // nil means true
    EnableCheckLog      *bool // nil means true
    RequireTenant       *bool // nil means true
    MaxGraphVisited     int
    MaxGraphFanout      int
    EvaluateAllModels   bool
    CheckLogQueueSize   int
    CheckLogRetention   time.Duration
    MaintenanceInterval time.Duration
    MaxBatchChecks      int
}
```
